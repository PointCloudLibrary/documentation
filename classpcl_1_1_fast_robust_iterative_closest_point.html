Detailed Description

template<typename PointSource, typename PointTarget, typename Scalar = float>
class pcl::FastRobustIterativeClosestPoint< PointSource, PointTarget, Scalar >

FastRobustIterativeClosestPoint implements the FRICP variant described in "Fast and Robust Iterative Closest Point", Zhang et al., 2021.

The solver relies on Welsch reweighting for robustness and optional Anderson acceleration for faster convergence.

Note
FRICP uses its own robust correspondence mechanism based on the Welsch function. The following inherited ICP settings have no effect:
  • setMaxCorrespondenceDistance() 閳?FRICP controls outlier rejection via the Welsch scale parameter instead.
  • Correspondence estimators, rejectors, and reciprocal correspondences are not used by this class.
  • setEuclideanFitnessEpsilon() and setRotationEpsilon() are not evaluated.
setMaximumIterations() controls the number of inner-loop iterations per Welsch scale stage. The outer loop may run multiple stages as the scale decays, so the total number of iterations can exceed this value.
Input point clouds must not contain NaN or Inf values. Non-finite points are not handled and will produce incorrect results.
pcl::FastRobustIterativeClosestPoint<PointT, PointT> reg;
reg.setInputSource (src); // src and tgt are clouds that must be created before
reg.setInputTarget (tgt);
// parameters may have to be tuned, depending on the point clouds
reg.setMaximumIterations (60);
reg.setTransformationEpsilon (1e-8);
pcl::PointCloud<PointT> output;
reg.align (output);

Valid range is (0, 1]. A value of 0 or a very small positive number is silently replaced by the default (0.5). Smaller values reduce the scale faster per outer iteration, while larger values keep it closer to the current value.
